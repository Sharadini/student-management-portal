# Student Management Portal

A static Student Management Portal created using HTML5 and CSS3 for the 26CS102 - Foundation of Full Stack assignment.

## Pages
- Home (`index.html`)
- About (`about.html`)
- Student Registration (`registration.html`)
- Courses (`courses.html`)
- Contact (`contact.html`)

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the navigation menu to visit the other pages.

## Note
This is a front-end demonstration. The registration and contact forms do not store or transmit data because no backend has been implemented.
